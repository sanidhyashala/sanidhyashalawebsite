# What is SanidhyaShala?

SanidhyaShala is a long-term educational platform focused on school mathematics.

It is not intended to become just another PDF repository.

The vision is to build a calm, premium, student-first learning ecosystem where technology quietly supports education.

The long-term goal is to create one of the most trusted mathematics learning platforms.

---

# Mission

Help students understand mathematics deeply.

Support teachers with meaningful educational tools.

Build a platform that values quality over quantity.

Academic

Student-first

# Architecture Philosophy

Content drives the application.

Not code.

Avoid hardcoded resources.

Prefer reusable components.

Prefer scalable architecture.

Avoid rewriting working systems.

---

# Development Rules

Never rewrite architecture without strong reason.

Never duplicate components.

Never ignore the Design System.

Always keep mobile experience in mind.

Always update documentation after major architectural decisions.
