# AI Collaboration Guide

Version: 1.0

---

# Purpose

SanidhyaShala is developed using multiple AI collaborators.

Each AI has different strengths.

This guide ensures that every collaborator works toward the same vision.

---

The project documentation is the highest source of truth.

04_COMPONENT_GUIDELINES.md

# Shared Rules

Never rewrite working architecture.

Never ignore existing documentation.

Never introduce inconsistent UI.

Never duplicate components.

Always explain major changes.

Always preserve existing functionality.

# Code Review Checklist

Before accepting generated code:

Architecture respected?

Design System followed?

Components reusable?

Performance acceptable?

Mobile friendly?

No duplicated logic?

Readable?

Future-proof?

If any answer is "No",

revise before merging.

---

# Prompting Rules

Always provide:

Project context

Current objective

Relevant documentation

Current architecture

Expected outcome

Never ask AI to generate code without context.

---

# Multi-AI Collaboration

Different AI systems may work on different parts.

Every contribution should remain consistent with the project documentation.

The project should always feel as though it was built by one engineering team.
