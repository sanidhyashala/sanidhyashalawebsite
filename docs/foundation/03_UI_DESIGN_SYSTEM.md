# SanidhyaShala UI Design System

Version: 1.0

---

# Design Philosophy

SanidhyaShala should feel:

Calm

Minimal

Professional

Premium

Academic

Focused

The interface should never distract students from learning.

Every design decision should reduce cognitive load.

---

# Brand Personality

Not flashy.

Not childish.

Not overloaded.

The platform should feel similar to:

Notion

Apple Education

Stripe Documentation

Linear

Clean.

Elegant.

Trustworthy.

---

# Border Radius

Cards

12px

Buttons

10px

Inputs

10px

Modals

16px

Large Sections

20px

Never use sharp edges.

---

# Shadows

Very soft.

Avoid heavy shadows.

Cards should appear elevated but lightweight.

---

# Typography

Headings

Bold

Clear hierarchy

Readable

---

Body

Comfortable reading size

High contrast

Never too small

---

Reader

Text should maximize readability.

---

# Buttons

Primary

Solid Blue

White Text

Rounded

Hover animation

---

Secondary

Border

White background

Slate text

---

Danger

Red

Only for destructive actions.

---

# Cards

Cards should always have:

Padding

Rounded corners

Soft border

Soft shadow

Consistent spacing

---

# Icons

Use simple outline icons.

Avoid decorative icons.

Every icon should have meaning.

---

# Spacing

Large whitespace.

Comfortable reading.

Never overcrowd the interface.

---

# Animations

Subtle only.

Allowed:

Fade

Slide

Scale

Skeleton loading

Not allowed:

Bouncing

Spinning everywhere

Flashy effects

---

# Mobile First Rules

Touch targets

Minimum 44px

Buttons

Easy to tap

Cards

Full width

Navigation

Simple

PDF

Maximum screen usage

---

# Reader Experience

The PDF should always remain the hero.

Everything else is secondary.

Toolbar should never dominate the screen.

---

# Accessibility

High contrast

Readable fonts

Keyboard friendly

Screen reader friendly

Visible focus states

---

# Consistency Rules

Never invent new button styles.

Never invent new card styles.

Never invent new spacing.

Reuse existing components.

---

# Golden Rule

Every new component must feel like it has always belonged to SanidhyaShala.

If it looks different, redesign it.

Not the system.

---

End of Design System
